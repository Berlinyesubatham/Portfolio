About Me

Turning requirements into working software.

I'm Berlin, a full-stack developer comfortable moving between the browser and the backend. I build interfaces with HTML, CSS, JavaScript, React and Bootstrap, and the systems behind them with Python, Flask, Machine Learning, C and MySQL — with Git keeping every step of the process tracked and reversible.

My focus is on clean, maintainable code and interfaces that don't get in the user's way. I've applied that across real projects — from data-driven admin tools to booking and e-commerce style sites.

I'm naturally curious and always excited to learn. When I discover a new idea or technology, I enjoy exploring how it works, practising it, and turning that knowledge into something useful.

  • Full-stack development, end to end
  • Responsive, accessible interfaces
  • Relational database design
  • Git-based collaborative workflow
  • Curious, continuous learner
